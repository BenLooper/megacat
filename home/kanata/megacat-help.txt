MEGACAT PAD — three-layer tmux command surface
============================================================

LAYER MODEL
  base  (default)         session map: Key N -> session N
  read  (hold kprt)       non-mutating fzf popups
  write (hold kp+)        mutating verbs

MODIFIERS (momentary; both tall right-column keys)
  kprt held  -> read layer   (lower tall key)
  kp+  held  -> write layer  (upper tall key)

TARGET MODEL (v2)
  kanata's cmd subprocess is NOT a tmux client, so there is no "current
  session" from its vantage. Each script first resolves an attached client
  via `tmux list-clients -F '#{client_name}' | head -n 1`, then uses that
  client as the explicit target: switch-client -c $CLIENT -t N,
  display-popup -t $CLIENT, display-message -t $CLIENT. Repo ops cd into
  the resolved client's `#{pane_current_path}` so they hit the right repo
  even when fired from the pad.
  v2 picks the lexicographically-first attached client (single-window use).

  SEAM (not built): two refinements deferred — (a) the ~/.cache/megacat/target
  file, so Base can target a session you are NOT currently looking at; (b)
  a non-default client picker for the multi-window case. Do not build yet.

===========================================================
ENCODER  (rotary knob + click; separate /dev/input/macropad-encoder)
===========================================================
  kanata grabs the Consumer Control interface (eventN) via linux-dev list
  syntax. The EK21's rotary knob emits Consumer-page keys per detent, not
  mouse wheel events:
    twist clockwise         -> KEY_VOLUMEUP   (evdev 115)
    twist counter-clockwise -> KEY_VOLUMEDOWN (evdev 114)
    click                   -> KEY_MUTE       (evdev 113)

  kanata TRANSLATES those keysyms (registered via deflocalkeys-linux as
  enc-up / enc-dn / enc-clk) into real mouse events emitted to /dev/uinput:
    enc-up -> (mwheel-up 50 120)    one 120-unit REL_WHEEL notch per detent
    enc-dn -> (mwheel-down 50 120)   same, opposite direction
    enc-clk -> mmid                 hold middle mouse while clicked = middle-click

  Result: the knob behaves as a scroll wheel + middle-click uniformly across
  ALL layers (pager, fzf preview, shell, browser, etc). The volume keys no
  longer reach the OS — kanata consumes them and emits scroll/click instead.
  Per-layer verbs come later as one-alias-swaps (same pattern as the
  keyboard stubs). Candidates:
    read  -> scrub the fzf preview / open match
    write -> confirm-by-twist gate for destructive verbs

  Setup:
    setup-macropad              one-time (adds the ATTRS{name} udev rule
                                targeting "RDMCTMZT EPOMAKER EK21 Consumer
                                Control")
    wsl --shutdown + restart    (or detach/attach via usbipd) so rule fires
    ls -la /dev/input/macropad-encoder   should exist
    readlink -f /dev/input/macropad-encoder | xargs udevadm info -q all
        # should report ATTRS{name}="...Consumer Control"

  Iteration: edit kanata.kbd, press KP- (lrld) to live-reload. NOTE the
  FIRST time enc-up/enc-dn/enc-clk enters defsrc (or after a kanata.kbd
  structural change that adds/removes defsrc columns), lrld is NOT enough —
  that first apply needs a full `systemctl --user restart kanata`. The
  long-running ExecStartPre also handles a /dev/uinput permission race on
  fresh WSL boots (kanata polls up to 30s for uinput perms before starting).

KEY FITTING
============================================================
  Fill a stub verb:
    1. Define the new verb as a `mkVerb` in home/kanata.nix.
    2. Add an alias in home/kanata/kanata.kbd defalias.
    3. Replace the matching `(cmd "megacat-stub" "...")` line in the
       layer with the new `@alias`. No structural change needed.

  Place a [MINE] key on the board:
    1. Run `evtest /dev/input/macropad` and press each [MINE] key.
       Record the reported KEY_* code (e.g. KEY_F13).
    2. Map it via `deflocalkeys-linux` (or use a recognized stock keysym)
       and add it to defsrc in the correct grid slot.
    3. Add the slot to every deflayer (base / read / write) — `_` will
       transparently fall through if you only want it bound on one layer.
    4. Place `@sk` / `@sr` / `@stub-mine` (or your alias) on that slot.

  Wire an encoder verb:
    1. Define the new verb as a `mkVerb` in home/kanata.nix.
    2. Add an alias `@enc-up`/`@enc-dn`/`@enc-click` in kanata.kbd defalias
       (the source keysyms enc-up/enc-dn/enc-clk are already registered via
       deflocalkeys-linux — no extra setup needed).
    3. Swap the matching `(mwheel-up 50 120)` / `(mwheel-down 50 120)` / `mmid`
       in the encoder row of the layer for the alias. Leave the other layers
       with the mwheel/mmio translation unless you want different per-layer
       behaviour.
