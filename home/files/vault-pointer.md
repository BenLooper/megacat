# The vault (personal knowledge)

Personal project knowledge lives in `~/vault` — a private, git-tracked
markdown repo that you read from and write back to. The `librarian` skill
is the workflow; the schema is `~/vault/AGENTS.md` (both short reads).

- When a task touches another project, a past decision, or "what do we
  know about X": read `~/vault/wiki/index.md` first and route from there.
- When a session produces durable knowledge (a decision, a lesson, a
  project state change), compile it back into the wiki per the schema.
- `~/vault` is private: never copy its contents into other repositories,
  never push it anywhere but its own private remote, never quote it in
  commit messages or public channels.
- If `~/vault` doesn't exist on this machine, skip silently.
